# Cinema OS

Cinema OS is an independently versioned project onboarded into AI Company.

The repository contains the first DEV backend skeleton: an Express API with in-memory film and
watchlist services, plus Jest tests. It is intentionally not yet a production system: persistence,
authentication, TMDB integration, and the web interface are still to be implemented.
